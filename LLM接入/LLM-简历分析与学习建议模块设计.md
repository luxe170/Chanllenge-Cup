# LLM 简历分析与学习建议模块设计

## 目标

将候选人简历转化为可用于人岗匹配、能力诊断和学习建议生成的结构化能力画像。LLM 在本模块中负责理解简历文本、抽取技能和经历、判断能力证据、生成诊断解释与学习建议；系统负责文件解析、数据校验、技能标准化、匹配计算、用户修正和结果留痕。

简历分析结果应服务于两个核心问题：

- 候选人现在具备什么能力，有哪些证据支撑。
- 候选人与目标岗位相比缺什么，下一步应该怎么补。

## 适用输入

- PDF、DOCX、TXT 等简历文件解析后的纯文本。
- OCR 后的扫描版简历文本。
- 用户手动输入或粘贴的简历内容。
- 用户选择的目标岗位或岗位方向。
- 岗位能力图谱中的目标岗位要求。

LLM 不直接处理文件格式解析。文件读取、OCR、文本提取应由独立模块完成，LLM 只消费已提取文本和必要上下文。

## 核心功能

### 基础信息抽取

识别候选人的基本信息：

- 姓名。
- 学历。
- 专业。
- 学校。
- 工作年限。
- 求职意向。
- 当前方向。
- 联系方式是否存在，正式展示时可脱敏。

基础信息应区分“明确识别”和“根据上下文推断”。推断结果必须降低置信度。

### 技能抽取与标准化

从简历中抽取技能实体，并映射到系统标准技能库：

- 编程语言。
- 框架工具。
- 算法模型。
- 数据库与中间件。
- 云平台与部署能力。
- 测试、安全和工程实践。
- 产品、数据分析或业务能力。

每个技能应包含技能名称、标准技能 ID、熟练度、证据片段、关联经历、置信度和来源类型。

熟练度建议分为：

- 了解：课程、阅读、简单使用。
- 熟悉：参与项目，有基础实践。
- 掌握：能独立完成模块或任务。
- 精通：主导复杂项目，有优化、架构或成果指标。

LLM 应避免只因为技能词出现就给高熟练度。熟练度必须结合上下文、角色、行动动词和项目结果判断。

### 经历结构化

将教育、项目、实习和工作经历转成结构化内容：

- 经历名称。
- 时间范围。
- 所属组织或项目背景。
- 候选人角色。
- 使用技术。
- 主要工作。
- 个人贡献。
- 结果指标。
- 可支撑的技能。

经历抽取应重点区分“团队做了什么”和“候选人本人做了什么”。缺少个人贡献的经历应标记为证据不足。

### 能力画像生成

综合简历形成候选人画像：

- 技术方向。
- 核心优势。
- 能力短板。
- 工程实践成熟度。
- 算法或业务理解深度。
- 项目证据强弱。
- 简历完整度。
- 与目标岗位的相关性。

能力画像不应只复述简历内容，而应把技能、项目和岗位要求关联起来。

### 人岗匹配解释

在系统完成匹配打分后，LLM 根据匹配结果生成自然语言解释：

- 为什么匹配。
- 哪些技能已经覆盖岗位要求。
- 哪些项目可以作为岗位证据。
- 哪些关键能力缺失。
- 哪些差距最影响匹配分。
- 候选人适合的备选岗位方向。

匹配分数建议由可解释规则或模型计算，LLM 负责解释和表达，不直接决定最终分数。

### 学习建议生成

基于目标岗位要求、简历能力画像和匹配差距，生成个性化学习建议。

学习建议应包含：

- 优先补齐的技能。
- 每项技能为什么重要。
- 当前差距来自哪里。
- 建议学习路径。
- 阶段目标。
- 可验证产出。
- 预计周期。
- 推荐练习项目。

学习建议应按优先级组织，不要输出泛泛的资料清单。每条建议都应对应一个岗位能力缺口或项目证据缺口。

建议分为三类：

- 短期补齐：1 到 2 周内能完成的基础技能和简历修正。
- 中期项目：2 到 6 周内形成可展示项目证据。
- 长期提升：架构能力、模型能力、复杂工程经验等高阶能力。

### 简历优化建议

LLM 可以额外输出简历修改建议：

- 哪些技能缺少项目证据。
- 哪些项目描述过空。
- 哪些经历与目标岗位关联弱。
- 哪些地方需要补充量化指标。
- 哪些技能表述应归一化。
- 哪些内容可能造成误判。

这部分建议应作为候选人可编辑内容，不直接影响系统匹配分。

## 输出要求

输出应覆盖：

- 简历任务 ID。
- 候选人基础信息。
- 技能列表。
- 经历列表。
- 能力画像。
- 目标岗位相关性。
- 匹配解释。
- 学习建议。
- 简历优化建议。
- 证据片段。
- 置信度。
- 用户修正记录。
- LLM 模型名称、提示词版本和生成时间。

所有可影响匹配的字段都必须能追溯到简历原文或用户修正记录。

## 用户修正机制

简历分析必须允许用户修正：

- 新增技能。
- 删除误识别技能。
- 修改熟练度。
- 修改目标岗位。
- 修正项目经历。
- 补充证据说明。

用户修正后的结果应优先于 LLM 原始输出，并在后续匹配和学习建议中生效。

## 质量指标

建议评估：

- 技能抽取 micro-F1。
- 熟练度分类准确率。
- 项目经历字段完整率。
- 目标岗位识别准确率。
- 学习建议与岗位缺口的一致性。
- 用户修正率。
- 解析失败率。

扫描版简历、表格简历、中英文混排简历和无技能简历应作为重点测试样本。

## 后续接入建议

简历解析可采用异步任务方式。上传后先完成文本提取，再调用 LLM 分析，最后返回结构化结果。若 LLM 不可用，应明确返回降级状态，不能伪造完整分析结果。
