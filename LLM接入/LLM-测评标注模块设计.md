# LLM 测评标注模块设计

## 目标

为 JD 解析、简历分析和人岗匹配建立可复核、可追溯、可量化的评测标注流程。LLM 在本模块中只能作为初标助手、质检助手和错误分析助手，不能作为唯一金标准来源。

正式评测必须基于人工确认的金标准。LLM 标注结果必须明确标记为草稿、候选或辅助意见。

## 适用范围

本模块覆盖三类评测：

- JD 解析评测。
- 简历分析评测。
- 人岗匹配评测。

每类评测都应区分数据选择、LLM 初标、人工复核、金标准冻结、系统预测、指标计算和错误分析。

## 核心功能

### 测试集构建

选择覆盖充分的样本：

- 多家公司。
- 多招聘平台。
- 多时间窗口。
- 不同岗位类别。
- 新兴岗位。
- 已有岗位。
- 边界样本。
- 噪声样本。
- 中英文混排样本。

测试集应与规则开发、提示词调试和图谱构建数据隔离，避免数据泄漏。

### JD 初标

LLM 对 JD 测试集生成第一版标注草稿：

- 是否属于目标范围。
- 标准岗位。
- 新岗位候选。
- 技能列表。
- 必备或加分。
- 职责。
- 业务场景。
- 证据片段。
- 置信度。

JD 初标结果只能作为人工复核底稿。人工复核后才可以进入正式金标准。

### 简历初标

LLM 对简历测试集生成初标：

- 候选人基础信息。
- 技能列表。
- 熟练度。
- 项目经历。
- 技能证据。
- 目标岗位。
- 工作年限。
- 简历完整度。

简历初标同样必须经过人工复核。对于扫描版、表格版、内容缺失或格式异常简历，应单独记录解析失败原因。

### 匹配标注辅助

LLM 可辅助评审“简历-岗位”样本对：

- 候选人最匹配岗位。
- Top-3 可接受岗位。
- 匹配等级。
- 关键优势。
- 关键缺口。
- 判断依据。

最终匹配标签应由具备招聘、技术或赛题背景的评审确认。若评审冲突较大，应引入第三人裁决或剔除样本。

### 标注一致性检查

LLM 作为质检助手发现标注问题：

- 同一技能被标成多个名称。
- 同一岗位被归到不同标准岗位。
- 必备和加分标准不一致。
- 标签缺少证据片段。
- 证据片段无法支撑标签。
- 边界样本处理前后不一致。
- 标注员之间冲突较大。

质检输出应生成问题清单，由人工确认是否修改金标准。

### 金标准冻结

人工复核后的标注应形成冻结版本：

- 标注版本号。
- 数据版本号。
- 标注员信息。
- 复核状态。
- 冲突处理记录。
- 冻结时间。
- 禁止自动覆盖的金标准文件。

一旦进入正式评测，金标准不能被 LLM 或系统预测结果自动改写。

### 系统预测对比

将系统输出与金标准对比，计算指标：

- JD 技能抽取 Precision、Recall、F1。
- JD 岗位标准化准确率。
- 必备/加分分类准确率。
- 简历技能抽取 micro-F1。
- 简历熟练度分类准确率。
- 项目经历字段完整率。
- 人岗匹配 Top-1 Accuracy。
- 人岗匹配 Top-3 Accuracy。
- 高中低匹配等级准确率。

评测报告应保留每个失败样本的预测、金标准、差异字段和错误类型。

### 错误分析

LLM 可基于评测失败样本生成错误分析：

- 技能漏提。
- 技能误提。
- 技能归一错误。
- 岗位归类错误。
- 新岗位误报。
- 新岗位漏报。
- 必备/加分判断错误。
- 简历熟练度误判。
- 项目证据识别错误。
- 匹配排序错误。

错误分析结果用于改进提示词、词表、规则和审核策略，不能直接修改金标准。

## 标注流程

推荐流程：

1. 冻结待标注数据。
2. LLM 生成初标草稿。
3. 第一名人工标注员复核。
4. 第二名人工标注员独立复核关键字段。
5. 冲突样本由第三人裁决。
6. 生成金标准版本。
7. 系统生成预测结果。
8. 运行评测脚本。
9. 生成指标报告和失败样本清单。
10. LLM 辅助错误分析。

## 人工审核边界

以下情况必须人工确认：

- LLM 置信度低。
- 样本是边界岗位。
- 岗位存在多个合理归类。
- 技能证据不明确。
- 简历项目贡献不清晰。
- 匹配等级存在争议。
- LLM 与规则结果冲突。
- 两名标注员结果不一致。

## 输出要求

本模块应形成以下产物：

- LLM 初标文件。
- 人工复核文件。
- 冲突样本清单。
- 冻结金标准文件。
- 系统预测文件。
- 指标评测报告。
- 失败样本明细。
- LLM 错误分析报告。

每个产物都应记录数据版本、模型版本、提示词版本、生成时间和责任来源。

## 质量与可信边界

对外表达时可以说：

- LLM 用于标注初稿、质检和错误分析。
- 正式评测金标准经过人工复核。
- 评测报告包含样本级差异和错误类型。

不应说：

- 评测金标准完全由 LLM 自动生成。
- LLM 评分等同于人工专家评分。
- 没有人工复核也能证明准确率达到要求。

## 后续接入建议

优先实现离线标注流水线和标注复核表，而不是在线评测接口。正式评测入口应只读取冻结金标准和系统预测结果，保证每次评测可复现。
