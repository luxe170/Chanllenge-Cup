# 字节跳动社招研发职位爬虫

脚本通过公开招聘页面自动选择“研发”职位，遍历全部列表页，并进入每个职位详情页采集职位名称、地点、职位类别、发布时间、职位描述和职位要求。发布时间从详情页 HTML 内嵌 JSON 或页面加载的职位 JSON 源数据中提取，并统一输出为北京时间。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## 运行

先用一页验证环境：

```bash
python src/crawlers/bytedance_jobs_spider.py --max-pages 1 --output output/test_jobs
```

确认无误后抓取全部研发职位：

```bash
python src/crawlers/bytedance_jobs_spider.py
```

默认数据写入 `data/raw/bytedance_dev_jobs.jsonl` 和
`data/raw/bytedance_dev_jobs.csv`。站点当前有数千个研发职位，完整抓取需要较长时间。
脚本每成功抓取一条就追加到 `.jsonl`，中断后用相同命令重跑会跳过已完成职位。
CSV 会在首条记录写入后创建，并在每新增 25 条记录时刷新一次，无需等待全量任务结束。
已有记录若缺少 `publish_time`，重跑时会自动重新采集该职位以补齐字段。
最终 CSV 使用 UTF-8 BOM 编码，可直接用 Excel 打开而不乱码。

常用参数：

- `--workers 4`：详情页并发数，不建议设置过高。
- `--delay 0.8`：请求间隔，遇到限流时应调大。
- `--page-size 50`：列表页条数；网站若限制条数，脚本仍会继续翻页。
- `--show-browser`：显示浏览器，排查验证码或页面结构变化时使用。

请遵守目标网站的服务条款和 robots 规则，仅将公开招聘信息用于合法用途，避免高并发访问。
